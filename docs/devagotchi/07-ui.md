# 7. UI screens (desktop and phone)
[Index](../devagotchi-spec.md) · React Aria Components (`Dialog`, `Modal`, `Table`, `GridList`, `Tabs`, `Menu`, `Switch`, `TextField`, `Select`, `DisclosureGroup`, `ToastRegion`, `Meter`, `AlertDialog` pattern via `Dialog role="alertdialog"`, `Checkbox`, `TextArea`, `Tree`, `ProgressBar`) with our own CSS tokens, extending the existing `web/src/ui/*` wrappers. No shadcn and no Radix. Breakpoints match the existing board: ≥1024 px desktop layout, <640 px phone. Every list screen has an empty state and a loading state. All editors use `version` + If-Match and show `version_conflict` with a reload/merge prompt.

## Global
- **Grants chip** in the header (desktop: right side, phone: a bar under the header). It shows "N live grants · M high risk", is always visible while N>0, and has a menu with each grant, its countdown, and **Revoke**, plus **Revoke all**.
- **Requests badge** (pending access requests) opens the Requests inbox. Optional browser notifications toggle in Settings.
- **High-risk banner** when an `unsandboxed`, `gui.*`, full-access, or high-severity grant is live (`reminder_style`). It cannot be dismissed while the grant lives.
- **Resume alert** (`Dialog role="alertdialog"`, modal, focus trapped): shown on every session resume while a full-access or unsandboxed grant is live ([04](04-access-flow.md#full-access-and-resume-alerts)). Buttons: **Continue**, **Revoke now**, **Pause machine**. No close button and no "don't show again".
- **"Unsandboxed allowed" marker** in the header whenever the unsandboxed policy is on, even with no live grants.
- **GUI active indicator**: the chip shows "GUI: laptop" while a GUI session is live, with **Stop** in its menu.

## Copy rules
- Plain language first, with technical detail collapsed. Risks always show severity as text and an icon, never colour alone.
- Never render secrets: inputs use `type=password`, there is no "show" toggle for stored keys, and tokens are shown once with a copy button and then masked.
- Times use the viewer's zone, with a zone label (e.g. "expires 7:40 PM EDT").

## Accessibility
React Aria provides keyboard/focus/ARIA behaviour. Countdown updates use `aria-live="polite"` at most once a minute. Revoke buttons are labelled with the grant ("Revoke shell access to laptop for codex").
